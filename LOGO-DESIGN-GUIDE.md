## 🎨 TAXCAT - Logo Design Specifications

### **Brand Overview**
```
Company Name: TaxCat
Tagline: Canadian Tax Solutions
Industry: Financial Services > Tax Preparation & Filing
Target Market: GTA professionals and small businesses (Toronto, Oakville, Burlington)
Target Audience: Professionals and small business owners aged 25-55
```

### **Design Style**
```
✅ Modern and clean
✅ Professional yet approachable
✅ Minimalist
✅ Tech-forward
✅ Trustworthy

❌ Avoid:
- Clipart or cartoon styles
- Overly corporate/stuffy
- Outdated designs
- Complex illustrations
```

### **Logo Type & Icon Preferences**
```
Logo Type: Combination mark (icon + text) OR Lettermark

Icon Options (ranked):
1. Lettermark "TC" in a badge/shield
2. Abstract financial symbol (growth/success)
3. Maple leaf integration (subtle Canadian pride)
4. Document/paper motif
5. Checkmark or approval symbol

Typography:
- Sans-serif
- Bold and confident
- Modern (Poppins, Inter, Montserrat style)
- Highly readable
```

### **Color Palette**
```
Primary Color:   #00A950 (vibrant green - trust, money, growth)
Secondary Color: #134A8E (blue - professional, Toronto pride)
Accent Color:    #F5A623 (gold - premium, confidence)

Color Mood: Fresh, trustworthy, modern, Canadian
```

### **Design Inspiration**
```
Reference Brands:
- Wealthsimple (modern fintech aesthetic)
- H&R Block (professional tax credibility)
- Stripe (clean, minimal tech)
- Toronto Blue Jays (local pride)

Feel: Modern financial app meets trusted Canadian service
```

## 🎨 LOGO USAGE GUIDELINES

### **File Formats Needed:**
- **SVG** - For web (scalable, small file size)
- **PNG** - Transparent background (various sizes: 512px, 1024px, 2048px)
- **PDF** - For print materials
- **Favicon** - 16x16, 32x32, 192x192 for website

### **Logo Variations to Request:**
1. **Full Color** - Primary version
2. **White** - For dark backgrounds
3. **Black** - For light backgrounds
4. **Icon Only** - Square badge without text
5. **Horizontal** - Icon + text side by side
6. **Stacked** - Icon above text

### **Minimum Sizes:**
- Digital: 120px wide minimum
- Print: 1 inch wide minimum
- Clear space: Equal to height of "T" or "E" on all sides
